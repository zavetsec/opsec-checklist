## Почему этот проект существует

Большинство советов по безопасности написаны с расчётом на западную инфраструктуру, сервисы и модели угроз. Пользователи в России и СНГ работают в принципиально других правовых, технических и надзорных условиях по сравнению с пользователями в США или ЕС. Этот проект предоставляет две самостоятельные редакции: одинаковая структура, одинаковая глубина — разные модели противников.

## Две редакции — один фреймворк, разные модели угроз

Это не перевод. Каждая редакция независимо адаптирована под свою целевую среду: инструменты, сервисы, правовые ссылки, модели угроз и техники специфичны для каждого региона.

## Возможности

Обе редакции имеют одинаковый интерактивный функционал:

- **Модели угроз** — выбери профиль *Приватность* или *Полная анонимность*, чтобы увидеть приоритетные пункты
- **Прогресс** — состояние сохраняется локально в браузере, переживает перезагрузку страницы, никуда не передаётся
- **Поиск** — полнотекстовый поиск по тексту пунктов, описаниям и шагам реализации (Ctrl+F)
- **Экспорт** — генерация отдельного HTML-отчёта о текущем состоянии выполнения
- **Прямые ссылки** — URL на любой конкретный пункт через якорь в хэше
- **Печать** — аккуратная печатная стилизация
- **Без зависимостей** — один самодостаточный HTML-файл, никаких внешних запросов\*

> \* Кроме Google Fonts, загружаемых при рендере. Для полностью офлайн-использования импорт шрифтов можно убрать — используются системные шрифты как запасной вариант.

## Использование

Скачай редакцию, соответствующую твоей среде угроз, и открой в любом браузере. Сервер не нужен.

```bash
git clone https://github.com/zavetsec/opsec-checklist
cd opsec-checklist

# Русская / СНГ редакция
# macOS:   open index.html
# Linux:   xdg-open index.html
# Windows: start index.html

# США / ЕС / Международная редакция
# macOS:   open index_en.html
# Linux:   xdg-open index_en.html
# Windows: start index_en.html
```

Или разместить на любом статическом хостинге или GitHub Pages.

## Модели угроз

**◐ Приватность** — защита от трекинга, брокеров данных и случайных угроз. Охватывает наиболее распространённый профиль риска: слежка рекламных сетей, credential stuffing, фишинг, захват аккаунтов и агрегация данных брокерами.

**◉ Полная анонимность** — защита от целевых атак, государственных противников, сценариев физического доступа и досмотра на границе. Актуально для исследователей безопасности, журналистов, активистов и любого человека с повышенной моделью угроз.

## Для кого это не подходит

Этот чеклист — не серебряная пуля, не военная доктрина и не гарантия защиты от компрометации государственного уровня. Он не защитит тебя, если государственная структура целенаправленно занимается именно тобой, имеет физический доступ к твоим устройствам или готова применить правовое давление и продвинутые технические возможности лично против тебя.

Это практический фреймворк для реального сокращения поверхности атаки и повышения операционной дисциплины против реалистичных угроз. OPSEC — это непрерывный процесс снижения излишней уязвимости, а не разовая настройка.

## Философия

> *«Сотри свою личную историю.»*
> — Карлос Кастанеда, «Путешествие в Икстлан»

Безопасность — это не продукт, а практика. Этот чеклист — отправная точка, а не гарантия. Твоя модель угроз уникальна. Читай каждый пункт, понимай *почему*, внедряй то, что относится к твоей реальной ситуации.
